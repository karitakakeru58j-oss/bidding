一致率は「その問題を除いた残りの回答」でAIに答えさせて計算しています。数字が上がっていけばAIがあなたの考えに近づいている、という目安です。

回答の記録をPBN形式（ブリッジの標準的な記録形式）で表示します。ここで操作しなくても、記録はこのページに自動で保存されています。


    

  


  
  

    

      
問題に答える

      
    
        
  1. 「問題」タブを開くと、手札と、ここまでのオークションが表示されます。あなたは南、パートナーは北です。東西は今はいつもパスします。
    2. 
        
  2. 下のビッドボックスから、次に出すビッドを1つ押します。
    3. 
        
  3. 理由を書きたいときは「理由」の欄に書きます。書かなくても大丈夫です。
    4. 
        
  4. 「この答えで決定」を押すと、AIの答えと理由が表示されます。
    5. 
        
  5. 「次の問題」を押して続けます。
    6. 
      

    

    

      
AIと答えが違ったとき

      
    
        
  1. 何もしなくても、あなたの答えが記録され、AIは次から「同じ流れで、点数と形がほぼ同じ手」ではあなたの答えに合わせます。
    2. 
        
  2. AIの答えの方が良かったと思ったら、「AIの答えに変える」を押します。
    3. 
        
  3. あとから直したいときは「記録」タブで、その問題の「直す」を押します。
    4.

  1. 回答が20〜30問たまったら、Claudeに「ビッド練習帳の回答を取り込んで、ルールを改善して」と頼んでください。
    2. 
        
  2. Claudeが記録を読み、あなたの答えと理由をもとにルール表を書き直します。
    3. 
        
  3. 書き直したあと、このページの「記録」タブで一致率が上がっているか確認できます。
