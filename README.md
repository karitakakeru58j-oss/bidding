# ビッド練習帳（ブリッジのビッドAI）

コントラクトブリッジのオークション（ビッド）を、決めたビッドシステムどおりに行うAIと、
クイズに答えることでAIを改善していく仕組みです。プレイ部分はありません。

## 実現方法の比較

| 方式 | 中身 | 難しさ | 必要な回答数 | 精度の見込み |
|---|---|---|---|---|
| A. ルールとして書き起こす | 「この流れで、この点数・形ならこのビッド」を表にする | 中（書くのはClaude、確認はあなた） | 0問から動く。直すのに数十問 | 書いた範囲はほぼ100%。書いていない流れは弱い |
| B. AIモデルに回答例を参照させる（似た例を探す／言語モデルに例を見せる） | あなたの答えを例として保存し、似た手を探して真似る | 仕組みは簡単だが、外部AIを使うと費用・速度・ブレの問題 | 場面ごとに数十〜数百問。全体では数千問 | 例が多い場面だけ良い。点数の境目で間違いやすい。理由を説明しにくい |
| C. 組み合わせ（採用） | Aのルール表を土台に、Bの「あなたの例」で上書き。たまった例と理由をもとにClaudeがルール表を書き直す | 中 | 0問から動き、20〜30問ごとに改善 | ルールの確実さ＋あなたの好みの反映。改善の度合いを一致率で確認できる |

**C を採用**しました。理由：ビッドシステムは約束事の集まりなのでルールで書くのが一番確実で、説明もできる。
一方、システムに書いていない判断（境目の点数、ハンドの質）はあなたの答えから学ぶのが早いからです。

## 仕組み

```
問題を出す ─→ あなたが答える（ビッド＋理由）─→ 記録（共有データベース / PBN）
     ↑                                              │
     │      AI = ①ルール表 → ②汎用判断 → ③あなたの似た回答で上書き
     └──────── Claudeがときどき記録を読んで①を書き直す ←┘
```

1. **ルール表**（`web/engine.js` の `RULES`）… 指定のシステムを書き起こしたもの。
2. **汎用判断** … ルール表にない流れでは、パートナーが示した点数・枚数から合計点とフィットを推定して判断（画面には【汎用判断】と表示）。
3. **あなたの回答例** … ルールがなく汎用判断になったときだけ、同じオークションの流れで、点数・各スートの枚数がほぼ同じ手
   （メジャーの枚数は完全に同じ）にあなたが答えていれば、その答えに合わせる。ルールがある所はルールを優先する
   （点数と枚数だけが近い手に合わせると、4枚メジャーの有無やスートの内容の違いで致命的な間違いが出たため。
   自分以外の回答を例にして確かめたところ、ルールの正解を間違えたのが10件、良くなったのが1件だった）。

## 今のシステム（エンジン v0.1.0）

- 5枚メジャー、長いマイナー（3-3は♣、4-4以上は♦）、1NT 15–17、2NT 20–21
- ストロング2♣：2♦ウェイティング、2♥スーパーネガティブ（0–3点）、2♣-2♦-2♥ はコキッシュ（2♠リレー）。
  コキッシュはバランス25点以上、ハート6枚以上、ハート5枚の5-5以上・5440のときだけ（ほかは2NT）
- ウィーク2♦/2♥/2♠（6枚・5–10点）、2NTはオウガスト
- 1NT（2NT・2♣→2NTも同じ仕組み）の後：ステイマン、ジャコビー・トランスファー、テキサス・トランスファー
- 3回目以降のビッドの見直し（一般原則。オープナーもレスポンダーも）：ルールがパスやゲームで止めようとしても、
  - 自分の点数＋パートナーの下限で、メジャーのフィット25点以上（ダミーポイント）なら4M、ノートランプ25点以上（ダミーポイントなし）なら3NT、マイナーのフィット28点以上なら5m
  - 合計33点以上でスラムがほぼ確定なら、フィットしたスートを切り札に4NT（RKCB。パートナーが直前に3の代以上でビッドしたスートか、スラムの仕組みで決まった切り札）、使えなければ6M／6NT
  - ルールにない4NT（直前のパートナーのスートのビッドが3の代以上）は、そのスートを切り札にしたRKCB
- 1NTオープン（と1NTオーバーコール）の後のレスポンダー（点数は補正込み。1NTオーバーコールは16〜18点なので、1点ずらして同じ仕組み）：
  - 5-4のメジャー：インビ未満は5枚の方へトランスファーしてパス。インビ以上はステイマン。
    2Mでフィットすれば従来どおり。2♦なら、5枚でない方のMを2の代で（2♥＝♠5・♥4、2♠＝♥5・♠4。パスできない）。
    オープナーは 2♠（♠フィット最低）／2NT（フィットなし最低）／3♥（♥フィット最低）／3NT（フィットなし最高）／4M（フィット最高）。
    フィットしてAKが多い・Mにアナーが寄っているときはコントロール紹介（2♠には3♠／4♣／4♦、2♥には4♣／4♦／4♥）
  - 5-5のメジャー（6-5・6-6も）：〜5点は2♦→2♥→2♠（オープナーは♥がずっと長いときだけ3♥）。
    6〜7点はステイマン：2Mに4M、2♦に3♥（オープナーはパス／3♠／3NT／4M）。
    8〜11点はステイマン：2Mにスプリンター（3oM）、2♦に3♠（オープナーは3NT／4M、フィットしてとても強いとき♥→4♣・♠→4♦）。
    12点以上は2♥→2♠→3♥（オープナー：♠フィット3♠、♥フィットは3NT＝♠／4♣／4♦のコントロール、スーパーミニマムやノーフィットは4♥／4♠）
  - 6-4のメジャー（7-4も）：スラムの可能性が薄ければ6枚のMだけ（トランスファー／テキサス）。
    12点以上はステイマン：2Mにスラムトライ、2♦に4♣（♥6・♠4）／4♦（♥4・♠6）。オープナーは興味があれば4♦／4♥、なければ4M
  - M6枚以上の1スーター（サイドに4枚スートなし）のスラムトライ（強さはパートナー平均3枚と合わせたダミーポイント）：
    16点以上（スラムのチャンス）は2の代でトランスファーしてから、6322・7222は4M（テキサスより強い手。オープナーは興味があれば4NT＝RKCB）、
    6331・7321などショートがあればジャンプシフト（スプリンター。オープナーはショートに無駄な点がなければ4NT、あれば4M）。
    18点以上（スラム確定）はテキサスから4NT（RKCB）
  - ステイマンの2Mでフィットした後のスラムトライ：3oM＝スプリンター（オープナーは1つ上でリレー、
    レスポンダーがショートを示す：♠が切り札なら3NT＝♥・4♣・4♦、♥が切り札なら4♣・4♦・4♥＝♠）、
    4♣＝バランス（5422も）のスラムトライ（オープナーは興味があれば4♦）、4♦＝RKCB（4♥＝1・4枚、4♠＝0・3枚、4NT＝2枚Qなし、5♣＝2枚Qあり）
  - M4・m5以上のGF：ステイマンでフィットしなければ3m（オープナーは興味があれば3NTより下でコントロール。1NT-2♣-2♥-3mの♠4枚は3♠＝やる気あり／4♠＝なし）
  - M5以上・m4以上のGF：トランスファーして3m（オープナーは3M＝Mのスラムトライ、4m＝mのスラムトライ、興味がなければ4M／3NT）
  - マイナー（4枚メジャーなし）：
    - 3m＝m6枚以上のインビ（mでトリックを取る手。目安：サイドにQ以上なし→AQの6枚・AJの7枚、サイドにK→QJ10・KJの6枚、サイドにA→Q109の7枚・K10の6枚）。
      目安の点数：スートのA4・K3・Q2・J1・10が0.5、7枚目から+1、サイドのA3・K2.5・Q1.2・J0.5で、5.5以上（インビかサインオフか微妙ならインビ）。
      オープナーはmにA・K・Qx以上があれば3NT
    - 2NT＝3♣を強制（♣6枚以上のサインオフ。m6枚以上のサインオフだけは4枚メジャーがあってもよい）。2♠＝マイナーステイマン（答え：2NT＝4枚マイナーなし、3♣、3♦）。
      ♦6枚以上のサインオフは3♦、マイナー5-5のサインオフは3mでパスか2NTに3♣
    - 3♥＝♣5枚以上、3♠＝♦5枚以上のスラムトライ（6枚以上かショートがあれば13点以上、5枚のバランスハンドは15点以上）。
      オープナーは興味がないか3枚サポートがなければ3NT、あれば4m。3NTの後もレスポンダーは合計33点以上なら6NT、33点あるか分からなければ4NT
    - マイナー4-4以上のスラムトライ（14点以上）は2♠から。2NTには 3M＝5-5以上のスプリンター
      （オープナーはそのスートに5点以上で3NT、なければ4m／やる気なしは5m）、4m＝5枚以上（オープナーはフィットすればコントロール、なければ4NTでサインオフ）、
      NT＝合計点の目安（33点あり得ない3NT／分からない4NT／33点あり37点なし6NT／37点分からない5NT／37点ある7NT）。
      3mでフィットしたら 3M＝スプリンター、4m＝ショートなしのスラムトライ、4NT＝RKCB
    - 4枚メジャーのないインビ（8〜9点）はステイマンから2NT（1NT-2NTは♣のリレーなので）
- メジャーのフィットを示すビッドの強さは**ダミーポイント**（HCP＋サイドのショート）で数える

  | サポート | ショート1枚 | ショート0枚 |
  |---|---|---|
  | 5枚への3枚 | +1 | +3 |
  | 5枚への4枚以上 | +4 | +5 |
  | 4枚への4枚 | +3 | +5（仮） |

- 1M後・3枚サポート：1NT＝4–5（切り札のKを持つときは3も）／ 2M＝6–10 ／ 1NT→3M＝11–12 ／ 2/1＝13以上
- 1M後・4枚以上サポート：

  | 強さ | 1♥の後 | 1♠の後 |
  |---|---|---|
  | 16以上（GF） | 2♠ | 2NT |
  | 強めの6–8 | 2NT | 3♣ |
  | 9–10 | 3♣ | 3♦ |
  | 11–弱めの12 | 3♦ | 3♥ |
  | 3–弱めの6 | 3♥ | 3♠ |
  | 強めの12–15・ショートなし | 3♠ | 3NT |
  | 強めの12–15・スプリンター | 3NT(♠)／4♣／4♦ | 4♣／4♦／4♥ |

- **強さの補正**（「強め／弱め」の判断）：HCPに次を足した点数で判断する
  - 3枚以上のスートの10は1枚につき1/3点
  - 5枚以上のスートのA・Kは1枚につき1/2点、Q・Jは1枚につき1/3点（1スートにつき最大1点）
  - 2枚以下のスートで、A・K（それより強い札）がないQ・Jは0.5点減らす（Qx→1.5点、Jx→0.5点、QJ→2点。QT・JTは減らさない）
  - Aの加点はなし
  - 6枚以上のロングスートは、トリックにできる見込みがあれば6枚目から1枚ごとに+1点（一般原則）。
    - スートの内容：A・Kのどちらかを持ち、A・K・Q・J・10のうち2枚以上（QJ97654のようなA・Kのないスートは加点しない）
    - エントリー：AKQのうち2枚以上ならスート自身で足りる。そうでなければサイドのAがあれば+1、サイドのKだけなら+1/2、
      サイドにA・Kがなければ加点しない（スートを立てても使えない）
    - 例：1M-1NT-2x で 32.32.432.AKQ432 は9点＋2点＝11点なので3♣で♣を示しながら招待。
      1♥-1♠ で A954.KJT643.—.K63 は♥6枚目の加点込みで4♠（♥5枚の A954.KJT64.—.K632 なら3♠）
    - そのスートの長さをビッドがすでに約束しているときは、約束した枚数を超えた分だけ加点する
      （6枚の2mリビッドは7枚目から。14点の♣6枚ちょうどは2♣、AKQ10の6枚とサイドのAJ10なら3♣）
    - オープン（1NTの範囲も）・プリエンプト（ウィーク2・3の代・4M）・オウガストには入れない（7枚は3の代で普通の長さ）
    - パートナーのスートに1枚以下のミスフィット（1m-1M-2m）では入れない
    - 2スーターの加点（+1.5…）や5枚以上のサポートの加点と重なる分は差し引く

  「強めのX点」＝補正込みでX.5点以上、「弱めのX点」＝X.5点未満。すべてのルールの点数はこの補正込みで判断する。
- オープン：補正込み11.5点以上。1・2番手ではQ・JのないAAKの11点もオープン。
  4番手は12点以上か、スペード5枚以上で「点数＋スペードの枚数」が15以上のときだけ
- ウィーク2：3〜10点。スートはトップ3枚中2枚、トップ3枚中1枚＋9以上の札3枚、またはスートに3点以上で手が6点以下。
  1・2番手でサイドにAがあればしない。レイズは9枚フィット（3枚）なら3のレベル、10枚フィット（4枚）なら4のレベル
- 1NTオープンの形には、6枚マイナーの内容が悪い（AKQが1枚以下）6322も含める
- 1のレベルのスートの応答：点数＋形（ボイド+3、シングルトン+1、4枚を超える1枚ごとに+1）が6以上。
  A・Kが1枚もない手は、シングルトンかボイドがあるときだけ
- 1♣-1NTは♣4枚以上を保証（♣のレイズとして働く）。♦4枚・♣4枚以上の弱い手は1NT。オープナーは♣4枚以上なら2♣
- 1m-1NTに、7枚以上の強いマイナーで16点以上なら3NT。1♦-1NTに18点以上で♣4枚以上なら3♣（ジャンプシフト）
- 1NTオープンの形には、6枚マイナーの6322と、6枚マイナーが弱くシングルトンがA・K・Qの6331も含める
- パス済みのパートナーの応答には、4枚フィットがあってもダミーポイント12点未満ならパス
- フィットした後のシングルトンのKは2点として数える
- フィットが決まった後（ジャンプレイズの後など）の別のスートのビッドはより上を目指す。ノンジャンプの4のレベルはコントロール
- マイナーのフィットでは、スラムへの興味はすぐにコントロールで示す（3Mのような切り札のビッドは使わない）
- 1m-1M-2mの後のインビ以上・GFの人工的なビッドに、オープナーはまずMの3枚サポートを示す
- パス済みのハンドの2のレベルのニュースート（本来GF）は6枚以上のインビテーション。パス済みの2のレベル以下の応答はフォーシングでない
- 1m-1M-2m の後（2のレベルのニュースートはインビ以上）：
  - 1♣-1♠-2♣：2♦＝インビ以上（♦と無関係・♥4枚なし）、2♥＝♥ちょうど4枚・インビ以上、2♠＝6枚以上のサインオフ（ニュースートではない）。GFは♥の有無で2♦か2♥から
  - ニュースート＝ペアのどちらもビッドしていないスート
  - 1♣-1♥-2♣：2♦＝インビ以上（♦と無関係）、2♥＝6枚以上のサインオフ、2♠＝GF（♠と無関係）
  - 1♦-1♥-2♦：2♥＝6枚以上のサインオフ（ニュースートではない）、2♠＝GF（♠と無関係）、3♣＝♥と♣の5-5以上・インビ
  - 1♦-1♠-2♦：2♥＝♥ちょうど4枚・インビ以上、2♠＝6枚以上のサインオフ、3♣＝♥4枚なしのGF（♣と無関係）
  - そのほかの3のレベルのニュースート＝5-5以上のインビ
- GFの局面（2/1の後、フォース・スートの後など）のNT：2NT＝12〜14、ジャンプの3NT＝15〜17、18以上は2NTから4NT（6NTへの招待）。
  GFでないときの3NTは単に3NTをプレイしたいという意味
- 回答例でオープンを真似するのは、オープンの強さ（11.5点など）があるときだけ
- 2mのリビッドは6枚以上。5枚の♣・♦は2mにせず1NT（バランスハンドを誤魔化す方が良い）
- 1m-2♠（5枚以上サポート7〜9）は6枚以上、5枚なら5-5や1345のような形のときだけ
- 1x-1M-2M-3M（招待）：オープナーはダミーポイント13点以上ならゲーム（パートナーがパス済みでも同じ）
- 1♣-1♥-2♣でGFは2♦でも2♠でも示せる：ストッパーがある方、両方あるなら低い方
- 1m-x-2m-4m はスラムトライ（♣サポートの招待は3mがあるため）
- 1NTリビッドの後、♠5枚・♥4枚以上の弱い手は2♥でサインオフ
- ジャンプレイズ（15〜17）の後、合計29点ぐらいあればコントロールでスラムトライ
- パートナーのスートのショートは加点せず、コントロールにも数えない
- 6枚スートのリビッドは強さで3通り：弱い15点以下＝2の代、強い15〜17点＝3の代、それより強い＝3NT（マイナー）／4M（メジャー）。
  このときAKQのうち2枚以上を持つ6枚以上のスートは、A・K・Q・Jの加点（1枚1/2・1/3）の上限を1点から2点に広げる
- 1m-1NTの後の18〜19点のバランスハンドは2NTでなく3NT
- リバースは1stスーツ5枚以上。18〜19点の4441でパートナーのスートが1枚なら2NT
- 4441の11点はオープン。KQの2枚・KQJの3枚は0.5点マイナス
- 1M-1NT-2x-3y（新しいスートのジャンプではない3の代）：yが6枚以上・Mが2枚以下で、6枚目からの加点込み11〜12点の招待。
  オープナーが2Mで6枚を示したときに♥/♠が2枚あれば、従来どおり3Mの方を選ぶ
- 1M-1NT-2m-3M（ジャンプ）は3枚サポートの11〜12点。1NTリビッドの後の2Mは6枚以上のサインオフ（オープナーはパス）
- オープンしたパートナー（下限11.5）の上限は14点と考える。弱いときは長い方のスートに戻す（プリファレンス）
- 7枚以上のメジャーで、8枚以上か、7-4以上の形でスートの内容が十分（AKQのうち2枚以上）なら4の代のプリエンプト
- ウィーク2（♦も）は、ほかのメジャーが5枚以上なら開けない。4枚は1・2番手では開けず、3・4番手（パートナーがパス）だけ開ける。
  3番手で6-4・スートの内容が良い（AKQのうち2枚以上）なら3の代で開ける（K742.85.AQT852.4 で3♦）
- NTの後のレスポンダーの点数は、シングルトンのKを1点低く数える（J942.J87.K.K7653 は1NTにパス）
- プリエンプト（ウィーク2・3の代・4の代・ウィークオーバーコール）に点数の下限はない。5点未満でも内容が十分ならビッドする
  （7枚以上：AKQのうち2枚以上、またはAKQの1枚とAKQJ10の2枚以上。例：T6.85.QT87642.96 で3♦）
- 1Mへの4枚サポートのレイズ（スプリンター以外：1♥-2♠、1M-2NT、1M-3♣、1M-3♦、1♠-3♥、1M-3M、1♥-3♠、1♠-3NT）の後のオープナーのニュースート：
  - レイズがGFでなく、ニュースートが3Mより低い：リインビテーション（ゲームの目安の1.5点下まで）。レスポンダーは示した範囲の上半分なら4M、下半分なら3M
  - レイズがGFでなく、ニュースートが3Mより高い：ショート（スラムトライ。パートナーの上限と合わせて32点以上になりうるとき）。例：1♠-3♦-4♥
  - レイズがGF：ノンジャンプのニュースート＝ショート（やる気があるとき）
  - スラムトライの後にパートナーがゲームで止めたら従う。ショートを示した後は、3回目以降の見直しでもショートの点を数えない
- スラムの可能性：パートナーの強い方（下限＋6点まで）を想定して合計32点以上になりうるか（11.5〜14点の想定は招待の判断だけ）
- 6-4は6枚スートからリビッド。オープンは回答例で変えない（ルールで決める）
- 2スーターの加点（+1.5）は、もう一方の長いスートにA・K・Qがあるときだけ
- GFでスラムの可能性があるとき：自分の1stスーツが4枚（5枚ならAKQのうち1枚以下）で、パートナーのスートが2枚以下（メジャーなら1枚以下）
  ならジャンプの3NT（15〜17）、そうでなければ4つ目のスート
- 1Mへの4枚サポートのレイズで2NT（強めの6〜8）以上は、HCPだけで5点以上ある手。足りなければ3M
- パス済みのパートナーの応答はフォーシングでない。4枚フィットがあり14点以下ならパス
- 長いスートを切り札にするとき（1NTへのトランスファー・テキサス＝パートナー平均3枚、1NTリビッド後＝平均2.5枚）、
  フィットの大きさでショートを加点：8枚→シングルトン+1/ボイド+3、8.5枚→+2.5/+4、9枚以上→+4/+5
- オープナーもフィットが分かったらダミーポイントで数える（パートナーの3枚に自分の5枚→シングルトン+1/ボイド+3）
- ダミーポイントの追加：K・Q・Jのシングルトンはショートの加点なし。5枚以上のサポートは1枚ごとに+1。
  5-5・6-4のように2スートで10枚以上ある手は、そのどちらかのフィットが分かったら+1.5（11枚なら+2.5）
- 1NTオープンの形：バランスハンドのほか、シングルトンがA・K・Qの4441・5431。ただしメジャーの5-4（5431）は1NTオープンしない。
  2NT（20点以上）への応答は、5枚以上のスートがあれば1点少なくても3NT（例：T43.98.K8652.J62）。
  5431は5枚スートの内容が悪い（AKQが1枚以下かつAKQJ10が3枚以下）か、パートナーがパスしているときだけ
- 1♣-1♠-2♥・1♣-1M-2♦・1♦-1♠-2♥はリバース（16点以上、1つ目のスート5枚以上）
- 回答例は、そのビッドが示す枚数（5枚メジャーなど）を手が満たすときだけ使う
- メモ（まだルールにしていない）：4枚以上のスートやパートナーのスートにアナーが集まり、2枚以下のスートが弱い手は点数効率が良く強め
- 1M-1NT：6点以上、またはAがあって4点を超えたら 1♣-1♦・1NTレスポンス：6点以上 ／ 1♥・1♠レスポンス：4点を超えたら
- 1♥に♥3枚・♠4枚：11点以上（ダミーポイント）のときだけ1♠、それ以外は3枚サポートのビッド
- 1M-1NTはセミフォーシング、2/1はゲームフォーシング
- 1m後：インバーテッド・マイナーレイズ（GF・13点以上）、1m-2♥＝4枚以上サポート・強めの10–12、
  1m-2♠＝5枚以上サポート・7–9（弱めの10まで）、1m-3m＝5枚以上サポート・3–6、
  4441/5440のダブルジャンプシフト（ショートを示す）

- **オープナーのリビッド**：2回目に3つ目のスートを言ったらアンバランスハンド確定。
  バランスハンドは（レスポンダーのメジャーに4枚サポートがあるとき以外）1NTか2NTでリビッドする。
- **2/1の後のメジャーのサポート**：3枚以上＝3M（スラムに興味あり）か4M（なし）。
  2Mが言えるときの2M＝ちょうど2枚。オープナーは6枚以上なら3M/4Mにレイズしてフィットが決まる
- **オープナーの2回目の新しいスート**（ランク：♣<♦<♥<♠、1のレベルの応答の後）
  - 1stスーツより低いランク：ノンジャンプ＝15点まで（強い15〜17点はノンジャンプの後、3回目に招待）、ジャンプ＝18点以上（GF）
  - 強い15〜17点で1stスーツに戻されたとき：a. 1Mレスポンスに3枚 → 2M ／ b. 1stスーツ6枚 → 3にレイズ ／
    c. アンビッドスートに1つ以上ストッパー → 2NT ／ d. アンビッドスート（2つなら低い方）
  - ジャンプの後のレスポンダー：1stスーツ3枚以上＝3のレベル ／ 自分の1stスーツ＝5枚以上 ／
    アンビッドスートのストッパーあり＝3NT ／ 3NTより下のニュースート＝そのスートのストッパーがなく困っている
  - 1stスーツより高いランク（2のレベル）＝リバース：16点以上
  - リバースの後のレスポンダー：1stスーツ＝3枚以上サポートFG ／ 2ndスーツのレイズ＝4枚以上FG ／
    自分の1stスーツ＝5枚以上・8点以下 ／ 2NTと4つ目のスートの低い方＝8点以下、高い方＝強い8点以上（GF）
  - 1NT応答の後のリバース：アンビッドスートの低い方と2NTのうち、低い方＝GFでない、高い方＝GF。
    ノンジャンプで3のレベルのニュースート＝5枚以上GF
  - オープナーはこれをパスできない。8点以下に対して18点ないなら2NT・3のレベルの1stスーツ・パートナーの5枚スートのレイズのどれか
    （多くはここでパス）、18点以上ならそれ以外でGF。強い8点以上に対してはアンビッドスートのストッパーがあれば3NT
- **ストッパー**（一般原則）：A／Kの2枚以上／Qの3枚以上／4枚以上。Mのフィットがないと分かったGFでは、
  3スートが出ていれば4つ目のスートのストッパーがあればNT、なければそのスート（ストッパーアスキング）、
  2スートなら両方のアンビッドスートが止まればNT、でなければ内容の良い方（ストッパーショーイング）
- **フォース・スート**：3つ目のスートの後、レスポンダーが4つ目のスートを言うと「追加の情報が欲しい」ゲームフォーシング。
  欲しい情報＝4つ目のスートのストッパー／レスポンダーのメジャーへの3枚サポート／スラムの可能性。
  どれも要らないとき（例：4つ目のスートにストッパーがありスラムもない）は3NTなどに直行する。
  オープナーの答えの順番：3枚サポート → 4つ目のスートのストッパー（NT） → 6枚の1つ目のスート → 5枚の2つ目のスート → 4枚の4つ目のスート → 1つ目のスート。
- **1NTリビッドの後：2ウェイ・チェックバック**
  - 2♣＝11–12点（オープナーは必ず2♦。弱いダイヤのサインオフにも使う）→ 2M(5枚)・3M(6枚)・2NT などで招待
  - 2♦＝13点以上でメジャーについて聞きたい（GF）→ オープナーは3枚サポート・4枚メジャー・2NTの順に答える
  - 1NTへのジャンプ（3のレベル）＝6枚以上の1スーターか5-5以上の2スーターのスラムトライ
- **スラム**
  - 基本はスモールスラムまで。グランドスラムはキーカード5枚と切り札のQがそろい、合計37点以上のときだけ。
  - FGでフィットを示すとき：ゲームより下（3Mなど）＝スラムに興味あり、ゲーム（4M）＝興味なし。
    その後の切り札以外のスートのビッドはコントロール（A・K・ショート）を示す。飛ばしたスートはコントロールなし。
  - やる気＝キーカード（4枚のAと切り札のK）の枚数＋示した点数の下限からの余力2点ごとに1。
    3Mのようなフィットとやる気を示すビッドはやる気1以上。コントロール紹介は1回ごとに、自分がそれまでに示したやる気より2多いやる気を示す
    （例：1♠-2♣-2NT-3♠-4♣-4♦-4♥ で 3♠＝1以上、4♣＝2以上、4♦＝3以上、4♥＝4以上）。
    スラムに有効な点数が11点未満ならやる気-1。有効でない点数＝パートナーのスートでないシングルトンのK・2枚以下のスートのQ・
    A・K・Qと一緒でない単独のJ、パートナーが1枚以下と示したスートのK・Q・J
    回数は、やる気1以上で1回、3以上で2回、5以上でコントロールのないスートが分かるまで何回でも。
  - 全スートにコントロールがあり、2人のやる気の合計が7以上なら4NT（RKCB 1430：5♣＝1か4、5♦＝0か3、5♥＝2・Qなし、5♠＝2・Qあり）。
    ボイドがあるときの答え：キーカードが偶数（2・4枚）→ 5NT、奇数（1・3枚）→ 6のレベルでボイドのスート（切り札より上なら6の切り札）。
    4NTが使えないときはスモールスラムに直接上がる。キーカードが2枚足りなければ5のレベルで止める。
  - マイナーのフィットでも同じ考え方を使う。
  - スプリンター（ビッドしたスートが1枚以下）：
    2/1GFに対するジャンプシフト（例：1♥-2♣-3♦＝♣4枚以上・♦1枚以下。やる気に依らない）／
    フィットが決まった後のジャンプシフト（例：1♠-3♣-4♦。スラムの可能性があるときだけ）／
    1Mレスポンスに対するダブルジャンプシフト（例：1♣-1♠-4♦＝♠フィット・♦1枚以下。ダミーポイント21点以上：
    オープナーのスラムトライは、パートナーのA2枚と切り札のQくらいでスモールスラムが9割近くメイクする強さが必要。18〜20点は4M）

仮に決めた部分（あとで直せます）：スラムの可能性の目安（自分の点数＋パートナーの推定点数の中央≧31）、
2/1の後のフィットは一番安い切り札のビッドで「興味あり」を示す、バルネラビリティは「なし」固定、
競り合いはなし（東西は常にパス）。1NTの後のマイナーの扱いは後で追加。

## 記録の形式

PBN 2.1。`[Auction]` は問題の時点まで（最後に `*`）。あなたの答えは独自タグで記録します：
`[Answer]` `[AnswerReason]` `[AIBid]` `[AIReason]` `[AISource]` `[AuctionDoubt]` など。

## 対戦（AI3体を相手にビッドする）

練習帳の「対戦」タブ。あなたが南、北（相方）と東・西はAI。東西も席を回して同じAIでビッドする（決めていない競り合いの場面はパスか汎用判断）。
オークションが終わると4人の手・最終コントラクト・各AIのビッドの理由を表示し、あなたのビッドとAIの答えが違ったところを示す。
「自分のビッドを記録に保存」で、南のビッドを回答記録（from: match）に入れられる。

## 敵の介入の後（オープン-(オーバーコール)-3番手）

自分たちの1の代のスートのオープンに、敵がナチュラルなオーバーコール（スート）をしたとき。フリーランの取り決め（2/1 GF・インバーテッドなど）は使わない。
練習帳の「出題する場面」で「敵の介入の後」を選ぶと、この場面（3番手・オープナーのリビッド・3番手の2回目）を出題する。

- NT：敵のスートのストッパーと点数。アンビッドのメジャー4枚以上を持たない。1NT＝8〜10（ストッパーがなくても点数があればビッド）、2NT＝11〜12、3NT＝13〜15
- ダブル：アンビッドのメジャー4枚以上（1♠-(2♣)-X＝♥4枚以上、1♦-(1♠)-X＝♥4枚以上）。1♦のオーバーコールには両メジャー4-4以上
  （2の代以上で両メジャーが残っていれば、どちらか4枚以上）。1♥のオーバーコールにだけは、1♠＝5枚以上・ダブル＝ちょうど4枚。
  1の代のオーバーコールには6点以上、2の代以上には8点以上（私の判断）
  - アンビッドのメジャーがない（1♠-(2♥) など）：マイナー4-4以上の8点以上、または敵のスートのストッパーがなく5枚スートのないインビ以上
  - オープナーのリビッドはフリーランで1Mレスポンスが来たときと同様（4枚あればレイズ、15〜17点はジャンプ、18点以上はゲーム）。
    アンビッドのメジャーがないダブルには、ストッパーと点数で2NT／3NT、なければマイナー4枚・6枚のリビッドなど
- 1♦のオーバーコールへの1M＝4枚以上（あとで5-4・5-5を示すこともある）。その後はフリーランの1Mレスポンスと同じ（NTはストッパーが必要）
- ノンジャンプの2の代のニュースート＝5枚以上のインビ以上（ダブルで示せるメジャーを持たない）。オープナーは3枚サポートで弱ければ3の代にレイズ、
  ギリギリ乗るならゲーム、余裕を持って乗るならキュービッド（GF）。ノンジャンプの3の代のニュースート＝5枚以上のGF
- ノンジャンプのレイズ＝シングルレイズ（Mは3枚、mは4枚以上。6〜10点）
- キュービッド＝パートナーのスートの3枚以上（マイナーは4枚以上）のインビ以上。メジャーのサポートは必ずキュービッドで伝える。
  1Mのキュービッドへのオープナー：3M＝弱いサインオフ、3Mより下のニュースート＝リインビテーション、4M＝インビに乗る、3Mより上のニュースート＝コントロール紹介。
  1mのキュービッドはストッパーかスラムの可能性を探る（オープナーはストッパーがあればNT、なければmに戻る）
- 1Mに4枚以上のサポート：6点まで＝3Mのプリエンプティブ・レイズ、7〜10点（ダミーポイント）＝3M以下のジャンプしたニュースート、11点以上＝キュービッド
- 1mの後のジャンプしたニュースート＝そのスート5枚以上＆4枚以上のサポートでインビ以上（3mを超えればGF）
- ダブルジャンプシフトとジャンプキュービッド＝スプリンター（1m：6枚以上のサポートとショートでスラムトライ、1M：フリーランと同様）
- オープンしたスートの3の代を超えるキュービッド（1♠-(3♣)-4♣など）は、インビ以上ではなくスラムトライ（16点以上・私の判断）。
  インビの手は、サポートがあればゲーム、なければ敵のスートのストッパーがしっかりあれば（A、Kx以上、QJx以上）3NT、なければダブル
  （ダブルの意味はアンビッドのメジャーだが、11点あるならパスしたくないので仕方なくダブル）
- ジャンプの取り決め（スプリンター・ジャンプしたニュースートなど）は4の代まで。5の代以上は自然（1♣-(3♥)-5♦は♦5枚＆♣4枚ではない）
- すべてに優先する原則：競り合いでゲームをビッドしたら、それをプレイしたいという意味（1♣-(3♥)-4♠＝♠7枚以上くらいで4♠をプレイしたい）。
  パートナーはパスする（3回目以降の見直しでもスラムに進めない）。3番手は♠7枚以上（または6枚で11点以上）なら直接ゲーム（私の判断）
- オープナーが18点以上（バランス）で敵のスートのストッパーがないときは、最低点のリビッドではなくキュービッド（GF・ストッパーを探す）。
  パートナーはストッパーがあれば3NT、なければフィットするスートか自分のスートを示す
- オープナーのリオープン（3番手・4番手がパスしたとき）。優先順：
  1. ノンジャンプのNT＝18〜19のバランスハンドと敵のスートのストッパー
  2. ニュースート＝5-5や6-4（強さの下限なし、17点まで）。それより強ければダブル→パートナーのビッド→2つ目のスートをビッド。
     ダブルに向かない手（アンビッドのメジャーが3枚未満など）は、2の代以下でビッドできれば5-4でも4枚のニュースート（5242で1♠-(2♣)-P-P に2♦）
  3. オープンしたスートのリビッド＝6枚以上、代に応じた強さ（2の代は最低点から、3の代は14点以上・私の判断）。16点以上はジャンプして招待
  4. ダブル＝アンビッドのメジャーが3枚以上で、敵のスートが2枚以下（5134で1♠-(2♣)-P-P は16点でもパス）。1の代のオーバーコールは強さにかかわらず、2の代は（点数−敵のスートの枚数）が11以上、
     3の代は13以上。4の代以上は敵のスートの枚数に関係なく17点以上
  - リオープンのダブルへのパートナー：敵のスートが5枚以上か4枚でアナー2枚以上ならパス（ペナルティ）、
    そうでなければアンビッドのメジャー4枚以上（9点以上はジャンプ）、オープナーのメジャーに3枚、ストッパーと8点以上でNT、5枚スート、の順（私の判断）
  - リオープンのNT（18〜19点）には6点以上で3NT、オープンしたスートのジャンプ（招待）には7点以上でゲーム（私の判断）
- その後の流れで決まっていないところは、汎用判断と3回目以降の見直し（ゲーム確定・スラムほぼ確定）で決める

## 敵のテイクアウトダブルの後（3番手）

自分たちの1の代のスートのオープンに敵がテイクアウトダブルをしたとき。練習帳の「敵のテイクアウトダブルの後（3番手）」で出題する。

- インビ以上のほとんどすべての手はリダブルから。例外（インビ以上でもスートで応答・レイズする）：
  - 1Mへの4枚以上のサポート：フリーランの各種レイズをそのまま使う（3枚サポートは6〜10点なら2M、インビ以上はリダブルから）
  - 1mへの5枚以上のサポート：インビ＝3mのジャンプレイズ、GF＝マイナーのジャンプシフト（1♣-(X)-2♦、1♦-(X)-3♣）。
    空いた2NTはプリエンプティブ・レイズ（5枚以上のサポートで弱い。6点未満・私の判断）。4枚のサポートは6〜9点なら2m、インビ以上はリダブルから
  - 5枚以上のメジャー：1の代で言えれば1M（その後は4番手がパスしていればフリーランと同様）。4枚のメジャーはインビ以上ならリダブルから、6〜9点なら1M
- 2/1（ノンジャンプの2の代のニュースート）＝6枚以上でインビ未満のto play
- それ以外の6〜9点は1NT（私の判断）
- オープナー：リダブルの後はパスして敵の動きを待つ、2/1はパス、2NTには3m、3mには14点以上でゲーム、ジャンプシフトにはゲーム（私の判断）

## パートナーのテイクアウトダブルの後（4番手）

敵のオープン-（パートナーのダブル）-パス-自分。練習帳の「パートナーのテイクアウトダブルの後（4番手）」で出題する。

- パスは、敵のスートを内容の良い6枚以上（AKQJ10のうち3枚以上・私の判断）持つ10点以上の手だけ。それ以外は弱くても必ずビッドする
- NT＝8〜10／11〜12／13〜15で代が分かれる（敵のスートのストッパーが必要・私の判断）
- スート：ノンジャンプ＝8点以下、ジャンプ＝インビ。メジャーのジャンプを枚数で使い分けられるとき（1の代で言えるとき）：
  2♠＝ちょうど4枚の9〜11点、3♠＝ちょうど5枚の8〜10点、4♠＝6枚以上の6〜10点、それより弱い・枚数が足りなければ1♠
- これを超えるGFの手はキュービッド。1m-(X)-Pのキュービッドは、メジャーちょうど4-4のインビ（4423の11点など）も含む
  - ダブルした側は4枚メジャーを示す（♥がなく♠4枚なら2♠）、なければ2NT
  - キュービッドした側：メジャー4-4のインビで、フィットしたら3M（これ以外のビッドはGF）。4枚メジャーがなければパス。GFならゲーム
  - ダブルした側：3Mのインビには14.5点以上で4M（私の判断）
- ビッド-ダブル-ビッドで回ってきた4番手（敵の3番手がビッドしたとき）：8点以上なら、敵のスートでない4枚以上のスート（メジャー優先）をビッド。
  ビッドできるスートがなければNT（8〜10＝一番安いNT、11〜12＝2NT、13〜15＝3NT）。8点未満はパス（私の判断）。
  GFはキュービッド、ジャンプはインビ（3の代まで・私の判断）。1m-(X)-2m のダブル＝両メジャー4-4以上、1M-(X)-2M のダブル＝両マイナー4-4以上
- ダブルした側のリビッド（パートナーがキュービッド以外）：基本はずっとパス。インビ（ジャンプ・2NT）には15点なくても答える（14点以上で受ける・私の判断）
  - 動き直す＝ストロングテイクアウト（18点以上などオーバーコールの上限を超えた手）
  - NT：ノンジャンプ＝18〜20、ジャンプ＝21以上（私の判断：23点以上はキュービッド）
  - レイズ（ノンジャンプの応答に対して、4枚サポート）：強さ＝点数＋シングルトンがあれば1。16〜18（15点の4441・16点の4432が下限、18点の4432が上限）はレイズ、
    19〜21（18〜20点の4441）はジャンプレイズ（1♠-(X)-P-2♥ だとジャンプレイズが即ゲームになるが仕方ない）
  - ニュースート：ノンジャンプ＝5枚ちょうどの18〜20点、ワンジャンプ＝5枚の20〜21点か6枚の20点まで
  - これらの上限を超えた2♣オープン級の手はキュービッド

## パートナーの介入の後（4番手・アドバンサー）

敵のオープン-（パートナーのスートのオーバーコール）-敵の応答（パス以外）の後の4番手。練習帳の「パートナーの介入の後（4番手）」で出題する
（敵の東西のオープンと応答は、席を回してこのAIで決める）。

- シングルレイズ・プリエンプティブレイズは通常通り（メジャーは3枚、マイナーは4枚以上のサポート。4枚以上で弱い（8点未満・私の判断）ならジャンプ）。
  メジャーに4枚以上のサポートで8〜10点は、3Mより下のジャンプしたニュースート（1♦-(1♠)-2♦-3♥ など）
  競り上がって4・5の代でしかレイズできないときも、4枚以上のサポート（か強い3枚）があれば、ほかのスートより先にレイズ（1♠-(2♥)-4♥ に .T863.AQT9862.32 は5♥）
- サポートのあるインビ以上は、オープンされた敵のスートのキュービッド
- 1の代のスートは基本的にナチュラル4枚以上・8点以上
- 2の代以上のジャンプしていないニュースートはto play（6枚以上・インビ未満）。ふつうは3の代まで、8枚以上か7-4なら4・5の代でも
- NT：1NT＝8〜12、2NT＝13〜14、3NT＝15点以上（敵のスートのストッパー）
- ダブル・リダブル：
  - パートナーが1の代でオーバーコールし、敵がレイズか1NT（1♣-(1♠)-2♣、1♦-(1♠)-1NT）：アンビッドの2スーター（理想は4-4以上）。
    2の代なら8点以上、3の代なら10点以上。5-4以上の形なら2点少なくても、示すべきメジャー4枚以上と点数があれば4-4でなくても
  - 3種類のスートが示され、4thスートがメジャー（1♣-(1♦)-1♥）：そのメジャー4枚以上（上限なし）。1の代で言えるときは1M＝5枚以上・ダブル＝4枚ちょうど、
    2の代以上の6枚以上でインビ未満はto playのビッド
  - 3種類のスートが示され、4thスートがマイナー（1♣-(1♠)-X、敵のダブルにはリダブル）：パートナーのスートにAKQのどれかを持つちょうど3枚のサポート、シングルレイズくらいの強さ
- パートナーのスートがマイナーのときは、メジャーを示すダブル・1Mをサポートより先にする。インビ以上でフィットもストッパーもないときは、パートナーがマイナーならキュービッド、メジャーならストッパーがなくてもNT

## 介入（オーバーコール）の学習（段階1：敵のオープンの直後）

- 回答は `data/overcalls.json` にも保存する（`node tools/overcall-report.js <フォルダ>`）。
- ウィークオーバーコールの候補から、AKQのうち2枚以上のスートでボイドか5-5以上の手は外す（普通のオーバーコール）。
- 練習帳の「介入」タブで出題する。東が1のレベルでオープンし、南（あなた）がすぐ次の手番。
  候補（1♦／1M／2m／2M／ウィークオーバーコール）を示すので、4つのパラメータ
  のうちリードショーイング・ゲームの可能性・競り合いを1〜5で評価し、介入する／しないを答える。
  プリエンプト性はビッドで決まる：1♦＝1、1M＝2、2m・2♥＝3、2♠・3m＝4、3♥以上＝5
- 回答の少ない種類から優先して出題する。「出題する種類」で1つの種類（ウィークは2の代・3の代も）だけに絞れる。回答は共有の保存場所の `overcalls` に入る。
- AI（`web/overcall.js`）：
  1. 候補を決める
  2. パラメータを推定する（最初は目安の式。回答がたまると、手の特徴からあなたの評価を予測するように補正）。
     リードショーイング＝ビッドするスートの内容（A・K・Q・J・10・9とAKQの2枚）、ゲームの可能性＝HCP、
     競り合い＝シェイプ（長い2スートの合計、シングルトン、ボイド）だけから判断する。
     同じ手でもオーバーコールの種類が違えば評価が違うので、種類ごとに分けて扱う：
     ゲームの可能性の目安は種類ごとの点数の幅（1♦ 9〜17、1M 7〜14、2m 9〜16、2Mは 9〜16で1〜5）。ウィークはスートの外の点数も見る（−0.2＋0.4×全体の点数＋0.2×スートの外の点数）、
     競り合いは1♦なら5枚で2以上、2Mは2mより高め（6322で2mは2、2Mは3）、敵のスートが短いほど高い
     （ボイド+1、シングルトン+0.6、ダブルトン+0.3、4枚以上-0.4）、
     ウィークは6枚なら1段ジャンプ、7枚以上なら3の代。ウィークの競り合いは2の代と3の代で基準を分ける
     （3の代は7枚が基本：6-4は2の代なら最高級、3の代では並以下）。補正もウィークは2の代と3の代で別々、
     2m・2Mの競り合いはオーバーコールするスートの長さが中心で、7枚目以降は大きく評価する（2m：5枚で1・6枚で2・7枚で4.5前後、2M：5枚で1〜2・6枚で3前後・7枚で5）、
     ゲームの可能性（ウィーク以外）には、内容が標準以上のスートの6枚目以降の加点（1枚+1点）を入れる、
     補正はその種類の回答が12件以上たまってから使う、
     回答からの補正は今は競り合いだけ学ぶ（リードショーイングとゲームの可能性は学ぶと当てはまりが悪くなったため）、
     ウィークは2〜9点（10点以上はジャンプせず普通にオーバーコール）で、ゲームの可能性の重みは最初から低め、
     スートの内容（リードショーイング）の重みは最初から高め、アンビッドのメジャー4枚を持ちゲームの可能性が高いとしない寄り
     （判断の6つ目の入力：メジャー4枚があるときの「ゲームの可能性−2」。最初の重み−1.5、回答から学ぶ）、
     1♦は♣のオープンに対して♦4枚でもビッドすることがある（出題の半分くらいは♦4枚）、
     回答からの補正と判断の重みも種類ごとに別々に学ぶ（ほかの種類の回答は使わない）
  3. 種類ごとのロジスティック回帰で「介入する確率」を出す（回答の少ない種類は最初の目安の重みに近い）
- 分析：種類ごとの重み（そのパラメータが1上がると介入しやすくなる度合い）と、する／しないの平均を表示。
  `node tools/overcall-report.js <フォルダ>` でも同じ分析を出せる。
- 1NTオーバーコールは学習せずルールで決める：1NTオープンと同じ形で補正込み16点以上（19点未満）、
  オープンのスートにストッパー（A、Kの2枚以上、Qの2枚以上、Jの3枚以上、または4枚以上）
- ダブル（テイクアウト）：敵のスートが3枚以下で、敵のスート以外のメジャーがすべて3枚か4枚の手。
  強さは補正込みの点数と敵のスートの枚数で「ダブルする確率」を学ぶ（敵のスートが短いほどダブルしやすい）。敵のスートにA以外のアナー（KQx・AJx・AQ10など）があるとダブルしない寄り（Axxは減点なし）。ダブルの形なら1♦・2mの候補よりダブルを優先する。
  ただし7枚以上のスートがある手はダブルの形にしない（1372で1♠に2♦など）。
  ダブルかスートのオーバーコールかは、メジャーの持ち方とスートの内容で決める：アンビッドのメジャーが4枚ならダブル寄り（ダブルを優先）、
  3枚だけならスートのオーバーコール寄り（リードショーイングが2より大きければオーバーコール。スートでオーバーコールするほどでなければダブルを考える）。
  スートでオーバーコールした回答は、ダブルの強さの学習には使わない。
- 2Mオーバーコール（2♥）を5枚でするのは、ゲームの可能性か競り合いの数値が十分ある手だけ（推定のゲームの可能性＋競り合いが4以上）。
  5332の弱い手（753.KQT42.AQ3.T6、754.AKJT2.J9.QT5）はしない
  出題：ダブルの形の手は「オーバーコール／ダブル／パス」の3択。オーバーコールの候補がない手は「ダブルの問題」（ダブル／パス）
  として出す（パラメータの評価なし）。記録の action に選んだもの（overcall／double／pass）が入る
- ビッドAI（`chooseCall`）は、敵のオープンの直後の手番ではこの判断を使う。それ以外の競り合いはまだパス。
