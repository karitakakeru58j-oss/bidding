# ビッド練習帳（ブリッジのビッドAI）

コントラクトブリッジのオークション（ビッド）を、決めたビッドシステムどおりに行うAIと、
クイズに答えることでAIを改善していく仕組みです。プレイ部分はありません。

## 実現方法の比較

| 方式 | 中身 | 難しさ | 必要な回答数 | 精度の見込み |
|---|---|---|---|---|
| A. ルールとして書き起こす | 「この流れで、この点数・形ならこのビッド」を表にする | 中（書くのはClaude、確認はあなた） | 0問から動く。直すのに数十問 | 書いた範囲はほぼ100%。書いていない流れは弱い |
| B. AIモデルに回答例を参照させる（似た例を探す／言語モデルに例を見せる） | あなたの答えを例として保存し、似た手を探して真似る | 仕組みは簡単だが、外部AIを使うと費用・速度・ブレの問題 | 場面ごとに数十〜数百問。全体では数千問 | 例が多い場面だけ良い。点数の境目で間違いやすい。理由を説明しにくい |
| C. 組み合わせ（採用） | Aのルール表を土台に、Bの「あなたの例」で上書き。たまった例と理由をもとにClaudeがルール表を書き直す | 中 | 0問から動き、20〜30問ごとに改善 | ルールの確実さ＋あなたの好みの反映。改善の度合いを一致率で確認できる |

**C を採用**しました。理由：ビッドシステムは約束事の集まりなのでルールで書くのが一番確実で、説明もできる。
一方、システムに書いていない判断（境目の点数、ハンドの質）はあなたの答えから学ぶのが早いからです。

## 仕組み

```
問題を出す ─→ あなたが答える（ビッド＋理由）─→ 記録（共有データベース / PBN）
     ↑                                              │
     │      AI = ①ルール表 → ②汎用判断 → ③あなたの似た回答で上書き
     └──────── Claudeがときどき記録を読んで①を書き直す ←┘
```

1. **ルール表**（`web/engine.js` の `RULES`）… 指定のシステムを書き起こしたもの。
2. **汎用判断** … ルール表にない流れでは、パートナーが示した点数・枚数から合計点とフィットを推定して判断（画面には【汎用判断】と表示）。
3. **あなたの回答例** … 同じオークションの流れで、点数・各スートの枚数がほぼ同じ手にあなたが答えていれば、その答えを優先。

## 今のシステム（エンジン v0.1.0）

- 5枚メジャー、長いマイナー（3-3は♣、4-4以上は♦）、1NT 15–17、2NT 20–21
- ストロング2♣：2♦ウェイティング、2♥スーパーネガティブ（0–3点）、2♣-2♦-2♥ はコキッシュ（2♠リレー）。
  コキッシュはバランス25点以上、ハート6枚以上、ハート5枚の5-5以上・5440のときだけ（ほかは2NT）
- ウィーク2♦/2♥/2♠（6枚・5–10点）、2NTはオウガスト
- 1NT（2NT・2♣→2NTも同じ仕組み）の後：ステイマン、ジャコビー・トランスファー、テキサス・トランスファー
- メジャーのフィットを示すビッドの強さは**ダミーポイント**（HCP＋サイドのショート）で数える

  | サポート | ショート1枚 | ショート0枚 |
  |---|---|---|
  | 5枚への3枚 | +1 | +3 |
  | 5枚への4枚以上 | +4 | +5 |
  | 4枚への4枚 | +3 | +5（仮） |

- 1M後・3枚サポート：1NT＝4–5（切り札のKを持つときは3も）／ 2M＝6–10 ／ 1NT→3M＝11–12 ／ 2/1＝13以上
- 1M後・4枚以上サポート：

  | 強さ | 1♥の後 | 1♠の後 |
  |---|---|---|
  | 16以上（GF） | 2♠ | 2NT |
  | 強めの6–8 | 2NT | 3♣ |
  | 9–10 | 3♣ | 3♦ |
  | 11–弱めの12 | 3♦ | 3♥ |
  | 3–弱めの6 | 3♥ | 3♠ |
  | 強めの12–15・ショートなし | 3♠ | 3NT |
  | 強めの12–15・スプリンター | 3NT(♠)／4♣／4♦ | 4♣／4♦／4♥ |

- **強さの補正**（「強め／弱め」の判断）：HCPに次を足した点数で判断する
  - 3枚以上のスートの10は1枚につき1/3点
  - 5枚以上のスートのA・Kは1枚につき1/2点、Q・Jは1枚につき1/3点（1スートにつき最大1点）
  - 2枚以下のスートで、A・K（それより強い札）がないQ・Jは0.5点減らす（Qx→1.5点、Jx→0.5点、QJ→2点。QT・JTは減らさない）
  - Aの加点はなし

  「強めのX点」＝補正込みでX.5点以上、「弱めのX点」＝X.5点未満。すべてのルールの点数はこの補正込みで判断する。
- オープン：補正込み11.5点以上。1・2番手ではQ・JのないAAKの11点もオープン。
  4番手は12.5点以上か、スペード5枚以上で「点数＋スペードの枚数」が15以上のときだけ
- ウィーク2：3〜10点。スートはトップ3枚中2枚、トップ3枚中1枚＋9以上の札3枚、またはスートに3点以上で手が6点以下。
  1・2番手でサイドにAがあればしない。レイズは9枚フィット（3枚）なら3のレベル、10枚フィット（4枚）なら4のレベル
- 1NTオープンの形には、6枚マイナーの内容が悪い（AKQが1枚以下）6322も含める
- 1のレベルのスートの応答：点数＋形（ボイド+3、シングルトン+1、4枚を超える1枚ごとに+1）が6以上。
  A・Kが1枚もない手は、シングルトンかボイドがあるときだけ
- 1♣-1NTは♣4枚以上を保証（♣のレイズとして働く）。♦4枚・♣4枚以上の弱い手は1NT。オープナーは♣4枚以上なら2♣
- 1m-1NTに、7枚以上の強いマイナーで16点以上なら3NT。1♦-1NTに18点以上で♣4枚以上なら3♣（ジャンプシフト）
- 1NTオープンの形には、6枚マイナーの6322と、6枚マイナーが弱くシングルトンがA・K・Qの6331も含める
- パス済みのパートナーの応答には、4枚フィットがあってもダミーポイント12点未満ならパス
- フィットした後のシングルトンのKは2点として数える
- フィットが決まった後（ジャンプレイズの後など）の別のスートのビッドはより上を目指す。ノンジャンプの4のレベルはコントロール
- マイナーのフィットでは、スラムへの興味はすぐにコントロールで示す（3Mのような切り札のビッドは使わない）
- 1m-1M-2mの後のインビ以上・GFの人工的なビッドに、オープナーはまずMの3枚サポートを示す
- パス済みのハンドの2のレベルのニュースート（本来GF）は6枚以上のインビテーション。パス済みの2のレベル以下の応答はフォーシングでない
- 1m-1M-2m の後（2のレベルのニュースートはインビ以上）：
  - 1♣-1♠-2♣：2♦＝インビ以上（♦と無関係・♥4枚なし）、2♥＝♥ちょうど4枚・インビ以上、2♠＝6枚以上のサインオフ（ニュースートではない）。GFは♥の有無で2♦か2♥から
  - ニュースート＝ペアのどちらもビッドしていないスート
  - 1♣-1♥-2♣：2♦＝インビ以上（♦と無関係）、2♥＝6枚以上のサインオフ、2♠＝GF（♠と無関係）
  - 1♦-1♥-2♦：2♥＝6枚以上のサインオフ（ニュースートではない）、2♠＝GF（♠と無関係）、3♣＝♥と♣の5-5以上・インビ
  - 1♦-1♠-2♦：2♥＝♥ちょうど4枚・インビ以上、2♠＝6枚以上のサインオフ、3♣＝♥4枚なしのGF（♣と無関係）
  - そのほかの3のレベルのニュースート＝5-5以上のインビ
- GFの局面（2/1の後、フォース・スートの後など）のNT：2NT＝12〜14、ジャンプの3NT＝15〜17、18以上は2NTから4NT（6NTへの招待）。
  GFでないときの3NTは単に3NTをプレイしたいという意味
- 回答例でオープンを真似するのは、オープンの強さ（11.5点など）があるときだけ
- 2mのリビッドは6枚以上。5枚の♣・♦は2mにせず1NT（バランスハンドを誤魔化す方が良い）
- 1m-2♠（5枚以上サポート7〜9）は6枚以上、5枚なら5-5や1345のような形のときだけ
- 1x-1M-2M-3M（招待）：オープナーはダミーポイント13点以上ならゲーム（パートナーがパス済みでも同じ）
- 1♣-1♥-2♣でGFは2♦でも2♠でも示せる：ストッパーがある方、両方あるなら低い方
- 1m-x-2m-4m はスラムトライ（♣サポートの招待は3mがあるため）
- 1NTリビッドの後、♠5枚・♥4枚以上の弱い手は2♥でサインオフ
- ジャンプレイズ（15〜17）の後、合計29点ぐらいあればコントロールでスラムトライ
- パートナーのスートのショートは加点せず、コントロールにも数えない
- 6枚スートのリビッドは強さで3通り：弱い15点以下＝2の代、強い15〜17点＝3の代、それより強い＝3NT（マイナー）／4M（メジャー）。
  このときAKQのうち2枚以上を持つ6枚以上のスートは+1点
- 1m-1NTの後の18〜19点のバランスハンドは2NTでなく3NT
- リバースは1stスーツ5枚以上。18〜19点の4441でパートナーのスートが1枚なら2NT
- 4441の11点はオープン。KQの2枚・KQJの3枚は0.5点マイナス
- 1M-1NT-2m-3M（ジャンプ）は3枚サポートの11〜12点。1NTリビッドの後の2Mは6枚以上のサインオフ（オープナーはパス）
- オープンしたパートナー（下限11.5）の上限は14点と考える。弱いときは長い方のスートに戻す（プリファレンス）
- 7枚以上のメジャーで、8枚以上か7-4以上の形なら4の代のプリエンプト
- パス済みのパートナーの応答はフォーシングでない。4枚フィットがあり14点以下ならパス
- 長いスートを切り札にするとき（1NTへのトランスファー・テキサス＝パートナー平均3枚、1NTリビッド後＝平均2.5枚）、
  フィットの大きさでショートを加点：8枚→シングルトン+1/ボイド+3、8.5枚→+2.5/+4、9枚以上→+4/+5
- オープナーもフィットが分かったらダミーポイントで数える（パートナーの3枚に自分の5枚→シングルトン+1/ボイド+3）
- ダミーポイントの追加：K・Q・Jのシングルトンはショートの加点なし。5枚以上のサポートは1枚ごとに+1。
  5-5・6-4のように2スートで10枚以上ある手は、そのどちらかのフィットが分かったら+1.5（11枚なら+2.5）
- 1NTオープンの形：バランスハンドのほか、シングルトンがA・K・Qの4441・5431。
  5431は5枚スートの内容が悪い（AKQが1枚以下かつAKQJ10が3枚以下）か、パートナーがパスしているときだけ
- 1♣-1♠-2♥・1♣-1M-2♦・1♦-1♠-2♥はリバース（16点以上、1つ目のスート5枚以上）
- 回答例は、そのビッドが示す枚数（5枚メジャーなど）を手が満たすときだけ使う
- 予定：スモーレン（1NT-2♣-2♦の後）はあとで教わる
- メモ（まだルールにしていない）：4枚以上のスートやパートナーのスートにアナーが集まり、2枚以下のスートが弱い手は点数効率が良く強め
- 1M-1NT：6点以上、またはAがあって4点を超えたら 1♣-1♦・1NTレスポンス：6点以上 ／ 1♥・1♠レスポンス：4点を超えたら
- 1♥に♥3枚・♠4枚：11点以上（ダミーポイント）のときだけ1♠、それ以外は3枚サポートのビッド
- 1M-1NTはセミフォーシング、2/1はゲームフォーシング
- 1m後：インバーテッド・マイナーレイズ（GF・13点以上）、1m-2♥＝4枚以上サポート・強めの10–12、
  1m-2♠＝5枚以上サポート・7–9（弱めの10まで）、1m-3m＝5枚以上サポート・3–6、
  4441/5440のダブルジャンプシフト（ショートを示す）

- **オープナーのリビッド**：2回目に3つ目のスートを言ったらアンバランスハンド確定。
  バランスハンドは（レスポンダーのメジャーに4枚サポートがあるとき以外）1NTか2NTでリビッドする。
- **2/1の後のメジャーのサポート**：3枚以上＝3M（スラムに興味あり）か4M（なし）。
  2Mが言えるときの2M＝ちょうど2枚。オープナーは6枚以上なら3M/4Mにレイズしてフィットが決まる
- **オープナーの2回目の新しいスート**（ランク：♣<♦<♥<♠、1のレベルの応答の後）
  - 1stスーツより低いランク：ノンジャンプ＝15点まで（強い15〜17点はノンジャンプの後、3回目に招待）、ジャンプ＝18点以上（GF）
  - 強い15〜17点で1stスーツに戻されたとき：a. 1Mレスポンスに3枚 → 2M ／ b. 1stスーツ6枚 → 3にレイズ ／
    c. アンビッドスートに1つ以上ストッパー → 2NT ／ d. アンビッドスート（2つなら低い方）
  - ジャンプの後のレスポンダー：1stスーツ3枚以上＝3のレベル ／ 自分の1stスーツ＝5枚以上 ／
    アンビッドスートのストッパーあり＝3NT ／ 3NTより下のニュースート＝そのスートのストッパーがなく困っている
  - 1stスーツより高いランク（2のレベル）＝リバース：16点以上
  - リバースの後のレスポンダー：1stスーツ＝3枚以上サポートFG ／ 2ndスーツのレイズ＝4枚以上FG ／
    自分の1stスーツ＝5枚以上・8点以下 ／ 2NTと4つ目のスートの低い方＝8点以下、高い方＝強い8点以上（GF）
  - 1NT応答の後のリバース：アンビッドスートの低い方と2NTのうち、低い方＝GFでない、高い方＝GF。
    ノンジャンプで3のレベルのニュースート＝5枚以上GF
  - オープナーはこれをパスできない。8点以下に対して18点ないなら2NT・3のレベルの1stスーツ・パートナーの5枚スートのレイズのどれか
    （多くはここでパス）、18点以上ならそれ以外でGF。強い8点以上に対してはアンビッドスートのストッパーがあれば3NT
- **ストッパー**（一般原則）：A／Kの2枚以上／Qの3枚以上／4枚以上。Mのフィットがないと分かったGFでは、
  3スートが出ていれば4つ目のスートのストッパーがあればNT、なければそのスート（ストッパーアスキング）、
  2スートなら両方のアンビッドスートが止まればNT、でなければ内容の良い方（ストッパーショーイング）
- **フォース・スート**：3つ目のスートの後、レスポンダーが4つ目のスートを言うと「追加の情報が欲しい」ゲームフォーシング。
  欲しい情報＝4つ目のスートのストッパー／レスポンダーのメジャーへの3枚サポート／スラムの可能性。
  どれも要らないとき（例：4つ目のスートにストッパーがありスラムもない）は3NTなどに直行する。
  オープナーの答えの順番：3枚サポート → 4つ目のスートのストッパー（NT） → 6枚の1つ目のスート → 5枚の2つ目のスート → 4枚の4つ目のスート → 1つ目のスート。
- **1NTリビッドの後：2ウェイ・チェックバック**
  - 2♣＝11–12点（オープナーは必ず2♦。弱いダイヤのサインオフにも使う）→ 2M(5枚)・3M(6枚)・2NT などで招待
  - 2♦＝13点以上でメジャーについて聞きたい（GF）→ オープナーは3枚サポート・4枚メジャー・2NTの順に答える
  - 1NTへのジャンプ（3のレベル）＝6枚以上の1スーターか5-5以上の2スーターのスラムトライ
- **スラム**
  - 基本はスモールスラムまで。グランドスラムはキーカード5枚と切り札のQがそろい、合計37点以上のときだけ。
  - FGでフィットを示すとき：ゲームより下（3Mなど）＝スラムに興味あり、ゲーム（4M）＝興味なし。
    その後の切り札以外のスートのビッドはコントロール（A・K・ショート）を示す。飛ばしたスートはコントロールなし。
  - やる気＝キーカード（4枚のAと切り札のK）の枚数＋示した点数の下限からの余力2点ごとに1。
    3Mのようなフィットとやる気を示すビッドはやる気1以上。コントロール紹介は1回ごとに、自分がそれまでに示したやる気より2多いやる気を示す
    （例：1♠-2♣-2NT-3♠-4♣-4♦-4♥ で 3♠＝1以上、4♣＝2以上、4♦＝3以上、4♥＝4以上）。
    スラムに有効な点数が11点未満ならやる気-1。有効でない点数＝パートナーのスートでないシングルトンのK・2枚以下のスートのQ・
    A・K・Qと一緒でない単独のJ、パートナーが1枚以下と示したスートのK・Q・J
    回数は、やる気1以上で1回、3以上で2回、5以上でコントロールのないスートが分かるまで何回でも。
  - 全スートにコントロールがあり、2人のやる気の合計が7以上なら4NT（RKCB 1430：5♣＝1か4、5♦＝0か3、5♥＝2・Qなし、5♠＝2・Qあり）。
    ボイドがあるときの答え：キーカードが偶数（2・4枚）→ 5NT、奇数（1・3枚）→ 6のレベルでボイドのスート（切り札より上なら6の切り札）。
    4NTが使えないときはスモールスラムに直接上がる。キーカードが2枚足りなければ5のレベルで止める。
  - マイナーのフィットでも同じ考え方を使う。
  - スプリンター（ビッドしたスートが1枚以下）：
    2/1GFに対するジャンプシフト（例：1♥-2♣-3♦＝♣4枚以上・♦1枚以下。やる気に依らない）／
    フィットが決まった後のジャンプシフト（例：1♠-3♣-4♦。スラムの可能性があるときだけ）／
    1Mレスポンスに対するダブルジャンプシフト（例：1♣-1♠-4♦＝♠フィット・♦1枚以下。スラムの可能性があるときだけ）

仮に決めた部分（あとで直せます）：スラムの可能性の目安（自分の点数＋パートナーの推定点数の中央≧31）、
2/1の後のフィットは一番安い切り札のビッドで「興味あり」を示す、バルネラビリティは「なし」固定、
競り合いはなし（東西は常にパス）。1NTの後のマイナーの扱いは後で追加。

## ファイル

- `web/index.html` … 画面
- `web/app.js` … 出題・回答の保存・記録・PBN書き出し
- `web/engine.js` … ビッドAI（ルール表・汎用判断・回答例の参照・配牌・PBN）
- `tools/selftest.js` … エンジンの動作確認（`node tools/selftest.js`）
- `data/` … 取り込んだ回答記録（PBN）を置く場所

## 記録の形式

PBN 2.1。`[Auction]` は問題の時点まで（最後に `*`）。あなたの答えは独自タグで記録します：
`[Answer]` `[AnswerReason]` `[AIBid]` `[AIReason]` `[AISource]` `[AuctionDoubt]` など。
